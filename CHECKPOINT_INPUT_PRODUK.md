# LapakPindah — Checkpoint Input Produk

Basis: Practical Challenge Modul 3 Dini(2).zip, dilengkapi file platform dari LapakPindah_Practical(7).zip.

Fitur: tambah produk, katalog, edit, aktif/nonaktif, hapus aman jika tidak memiliki transaksi. Produk baru langsung muncul pada pilihan penjualan.

PENTING: Penyimpanan masih sementara di memori (belum SQLite). Produk dan penjualan hilang setelah aplikasi dimulai ulang. Lokasi dan sesi masih demo sampai Modul 1 siap.

Jalankan dari folder ini: `flutter pub get`, `flutter analyze`, `flutter run -d edge` (atau Android).

Belum diuji dengan Flutter SDK dalam lingkungan pembuatan ZIP. Jika analyzer menunjukkan masalah, kirim hasilnya sebelum perubahan selanjutnya.
